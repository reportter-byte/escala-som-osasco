Atualização pela nuvem — sem banco de dados

A escala oficial é um arquivo JSON publicado pelo responsável. Os irmãos podem tocar em Atualizar escala para buscar alterações, sem perder a escala que já está armazenada no aparelho.

OneDrive: um link de compartilhamento normal pode abrir uma página HTML ou bloquear a leitura automática (CORS). Se acontecer, baixe o JSON no OneDrive e use Abrir arquivo baixado. Para o botão atualizar por URL, use um endereço que entregue o JSON diretamente e permita leitura pelo navegador.

Publicar nova carga — responsável

Após incluir ou aprovar alterações, clique em Gerar escala oficial. Substitua o arquivo escala.json na nuvem, mantendo o mesmo endereço compartilhado com os irmãos.

O arquivo público inclui somente nomes e escalas, não contém pedidos privados de troca. A publicação é manual: o arquivo baixado deve substituir o escala.json da hospedagem.
